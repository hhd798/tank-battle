# 坦克大战 · Tank Battle

一个**单文件**的 HTML5 Canvas 坦克大战游戏。没有构建步骤、没有依赖、没有网络请求——双击 `index.html` 就能玩。

![单文件](https://img.shields.io/badge/single--file-index.html-2fb86a) ![无依赖](https://img.shields.io/badge/dependencies-0-blue) ![许可证](https://img.shields.io/badge/license-MIT-green)

## 玩法

守住阵地，打退 **6 波**敌军坦克。

| 操作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` 或 方向键 |
| 瞄准 | 鼠标指向（也可用 `Q` `E` 旋转炮塔） |
| 开炮 | 鼠标左键 / `空格`（可长按连射） |
| 暂停 | `P` 或 `Esc` |
| 静音 | `M` |
| 重开 | `R`（结算画面） |

## 特色

- **可破坏地形**：砖墙能被炮弹击碎，钢墙打不穿，水面挡车不挡弹——善用掩体侧翼包抄
- **波次递进**：每波敌人更多、更快、射速更高；第 3 波起出现带标记的**精英坦克**
- **会思考的敌人**：绕墙转向避障、被挡住会脱困漫游、有炮弹袭来会侧闪，只有拿到视线才开火
- **手感与反馈**：屏幕震动、粒子/冲击波/硝烟、弹道拖尾、飘分、受击红闪、暗角
- **完整 HUD**：分数、波次、剩余敌军、生命、护甲条、装填进度、右下角小地图
- **音效**：WebAudio 实时合成，无需任何音频资源文件
- **移动端**：支持触摸瞄准与射击
- **单文件零依赖**：不联网、不加载外部资源，复制走一个文件就能跑

# 方式二：起个本地静态服务器

## 开发与自测

游戏逻辑跑在 Canvas 里，肉眼看不出的 bug（比如敌人卡住导致波次永远打不完）很容易漏掉。
仓库里带了一个无头烟雾测试：用最小的 DOM / Canvas / 定时器桩，在 Node 中**真实运行** `index.html` 里的游戏循环，
并由一个"自动作战机器人"操作玩家坦克（绕墙走位、保持交战距离、躲弹），用来验证：

1. 长时间运行不抛异常
2. 波次能正常推进到胜利结算（不会因敌人卡住而卡死）
3. 敌人能真正获得视线并交战
4. 结算后"再来一局"能正确重置
5. 玩家站着挨打时能正确触发战败结算

```bash
node test/headless-test.js                 # 自动作战，跑 240 秒
TB_SECONDS=60 node test/headless-test.js   # 自定义时长
TB_PASSIVE=1 node test/headless-test.js    # 玩家不还手，验证战败流程
TB_PROBE=1 node test/headless-test.js      # 逐秒打印状态探针
```

这个测试在开发中抓出过 5 个真实缺陷，包括：玩家出生点压在墙格边界导致**永远无法左右移动**、
敌人被墙挡住后原地卡死导致**波次打不完**、以及玩家阵亡后 `alive` 未复位导致**复活后子弹全部穿透、游戏永远不会输**。

## 代码结构

```
index.html                 全部内容：HTML + CSS + 游戏逻辑（约 1500 行，内部分区注释）
test/headless-test.js      无头烟雾测试（开发用，非游戏运行所需）
```

`index.html` 内的逻辑分区：

| 区块 | 说明 |
| --- | --- |
| 常量 / 关卡地图 | 24×16 网格，`#` 砖墙 `@` 钢墙 `~` 水 |
| 音效 | WebAudio 合成（枪声、爆炸、中弹、波次提示） |
| 地图工具 | 圆形碰撞、分轴贴墙滑动、视线射线（DDA） |
| 子弹与爆炸 | 子步进防穿墙、砖墙破坏、伤害结算 |
| 敌人 AI | 避障转向 + 卡死脱困 + 躲弹 + 视野开火 |
| 波次与生成 | 出生点选择、出生预警标记、波次推进 |
| 渲染 | 地面/砖墙/钢墙/水、坦克（车体与炮塔独立旋转）、粒子、HUD、小地图 |
| 输入 | 键鼠 + 触摸 |

文件末尾导出只读状态接口 `window.__tankBattleStats()`，供测试和浏览器控制台调试使用，不影响游戏行为。
